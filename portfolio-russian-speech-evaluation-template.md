# Шаблон оценки качества русскоязычной речи для AI-проектов

> Демонстрационный учебный материал, созданный с помощью ИИ. Реальной аудиозаписи здесь нет; прослушивание, измерения и клиентская проверка не выполнялись. Это не оплаченная работа и не подтверждение опыта в аудиоразметке.

## Назначение

Показать структуру аккуратной оценки русскоязычной речевой записи по заданным критериям. Реальные оценки следует выставлять только после прослушивания исходного аудио и сверки с инструкцией проекта.

## Карточка оценки

| Поле | Что фиксировать |
|---|---|
| ID записи | Идентификатор из задания, без личных данных говорящего |
| Язык и вариант | Русский; региональные особенности отмечать только при наличии оснований |
| Разборчивость | Понятно / частично понятно / неразборчиво |
| Произношение | Конкретные звуки или слова, если есть слышимая проблема |
| Темп и паузы | Естественность темпа, обрывы, слишком длинные паузы |
| Интонация | Соответствие смысла и коммуникативной задачи |
| Естественность | Звучит ли фраза как обычная русская речь |
| Шум и артефакты | Фоновый шум, клиппинг, эхо, обрезанные начала/концы |
| Уверенность | Высокая / средняя / низкая с кратким объяснением |

## Иллюстративный текстовый пример

Это только пример смысловой проверки расшифровки; аудио не предоставлялось.

**Ожидаемая фраза:** «Я смогу отправить документы сегодня после обеда».

**Вариант расшифровки A:** «Я смогу отправить документы сегодня после обеда».

- Смысл: сохранён.
- Лексика: естественная.
- Предлагаемое решение: принять текстовую расшифровку, если аудио действительно соответствует ей.

**Вариант расшифровки B:** «Я смогу отправить документы сегодня до обеда».

- Смысл: изменён — «после» заменено на «до».
- Влияние: меняется обещанный срок отправки.
- Предлагаемое решение: исправить слово после проверки аудио; не угадывать по контексту.

## Принципы качественной оценки

1. Не придумывать произношение, интонацию или дефекты, которых нельзя услышать.
2. Разделять ошибки распознавания речи и особенности реального произношения.
3. Сохранять смысл, числа, имена и временные указания.
4. Отмечать сомнения и снижать уверенность, если запись шумная или фрагмент неполный.
5. Не включать персональные данные говорящих в комментарии.
6. Следовать проектной шкале, даже если она отличается от этой демонстрационной формы.

## Ограничения

- Это шаблон и иллюстрация текстовой проверки, а не реальная оценка аудио.
- Не подтверждает опыт в фонетике, транскрипции, лингвистике или профессиональной аудиоразметке.
- Для настоящего задания потребуются исходные записи, инструкция заказчика и ручная проверка.
